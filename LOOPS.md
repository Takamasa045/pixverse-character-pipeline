# Operating loops

Use `SKILL.md` and `references/production-v1.md` for current contracts. Previous loops are preserved in `references/legacy-LOOPS.md`; their YAML/Remotion routing is legacy-only.

## Recurring character to next work

1. Resolve adopted entity revisions and supplied media; identify only missing material.
2. Separate identity, clothing/role, voice, world/props and scene state. Explain this work's permitted changes.
3. Pin revisions, prepare performance/reference conditions and hand the production to Shotpack as the sole coordinator.
4. Validate, plan and dry-run. Reuse current valid authorization; obtain a concrete reviewed scope only where necessary.
5. Produce only approved work, review/adopt takes and finish the timeline. Offer reusable successful assets as a new revision after review.

## Focused repair and resume

1. Translate the request to shot/take/time range and expected vs observed behavior.
2. Inspect the ledger and existing assets before any submission. Resume known IDs; reconcile unknown outcomes.
3. Try edit, captions or audio first. For generation, show affected dependencies and preserve original take/attempt history.
4. Invalidate affected derived output only; review continuity and the changed delivery. Do not regenerate unrelated media.

## Canvas round trip

Read capabilities and current graph, compare base/local/remote, merge one-sided edits, show conflicts, preserve unmanaged nodes and adopted history, then validate/apply/dispatch only owned targets. Mark affected local edits stale. Never use Create to bypass an unresolved Canvas job or unsupported node field.

## Migration and rollback

Inventory legacy inputs, IDs, context, actual files, missing QA/costs and storage. Import to separate new objects plus report. Do not modify originals or generate replacements. Keep old input/media/Git baseline and select the old runtime explicitly if rollback is needed; never run both paid paths concurrently.

## Core maintenance and evidence

Read the canonical core contract and nearest tests. Patch the Shotpack source, synchronize the vendored copy and verify identical hashes. Run relevant fault/contract tests and representative fixtures. Report exact limitations; fixture quality does not establish creative quality. Summarize reusable public-safe lessons in `references/`; keep pending work in `NEXT_ACTIONS.md` and lasting changes in `DECISIONS.md`.
