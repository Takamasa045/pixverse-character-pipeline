# production.v1 integration contract

This directory is the canonical shared core, vendored byte-for-byte into Character Pipeline by `tools/sync-core.mjs` (no runtime sibling dependency). Node >=22.18, built-in SQLite, no new npm dependencies. Source modules use ESM `.mjs`; public types live in `contracts.d.ts`.

All persisted data is JSON-compatible. IDs are strings. Times are integer milliseconds except `timeline.fps`. Credentials never belong in production data.

`Production`: `{schema_version:'production.v1', project_id, revision, context:{region,workspace_id}, brief:{original,intent,deliveries:[{id,locale,aspect,duration_ms,width,height}],assumptions:[]}, entities:[{id,revision}], assets:[{id,kind:'image'|'video'|'audio',path?,sha256?,provider_id?,region,workspace_id,provenance,qa?}], shots:[{shot_id,purpose,prompt,edit_duration_ms,entry_state,exit_state,camera,audio:{intent},references:[{asset,role,order,target?}],generation_strategy:'editable_shot'|'single_take'|'native_sequence',generation?:{backend:'create'|'canvas',mode,model,parameters,upper_credits,price_evidence},take_id?}], execution_policy:{allowed_scope:'planning_only'|'generation',max_credits, max_attempts}, timeline:{fps,clips:[{shot_id,take_id,source_in_ms,duration_ms}],audio:[],captions:[]}}`.

`GenerationIntent`: `{id,project_id,shot_id,attempt,backend,mode,model,parameters,inputs:[asset snapshots],context,upper_credits,price_evidence,capability_snapshot?,canvas?}`. ID SHA256 includes every resolved request field, backend/context/reference content and attempt, excluding cost evidence and UI-only fields. `parameters` use CLI registry names (snake_case); explicit false remains false. The executor adds idempotency key for supported Create image/video; client-request-id is tracing only.

`Take`: `{id,project_id,shot_id,intent_id,provider_id,kind,path?,sha256?,status:'completed'|'downloaded'|'reviewed'|'accepted',qa:{technical,creative,continuity,audio,reviewer,notes},stale:false,provenance}`. `completed` is never accepted automatically.

Adapter interface: `submit(intent)`, `status(intent,provider_id)`, `download(intent,provider_id,destination)`, returning `{results:[{id:string,status:'submitted'|'running'|'completed'|'provider_failed',kind,url?,path?,cost_credits?}], exit_code?,error?,raw?}`. Never throw away IDs on nonzero exits. Submit is called once after durable reservation+submitting state; crash/throw with no IDs becomes unknown_submission, never automatically resubmitted. `download` must not create new generation. Dry-run never calls adapters.

`store.mjs` owns durable execution/budget; `planner.mjs` owns resolved intents; `character.mjs` owns accepted entity revisions; `review.mjs` and `sync.mjs` own adoption and Canvas imports. `pixverse.mjs` and `canvas.mjs` form separate provider boundaries. `finish.mjs` accepts production + takes without Store coupling. `compat.mjs` imports old input into a new draft and migration report; it never rewrites a source.

References must carry `status:'accepted'` before paid work. Add only the relevant `entity_revisions` to each shot, so a voice or wardrobe change cannot invalidate unrelated requests. Use optional `jobs` with the same generation fields for independent voice/music/reference-image work; these are not counted in edit duration. Voice requests with identical resolved text/model/voice/performance/locale/context/attempt share one intent and list their original `owners`; aspect alone never duplicates voice. Record `locale`, `voice_revision` and `performance` when relevant. A reference's optional `controls` map detects conflicting values for the same `target` feature.

`canvas-sync` consumes `{base,local,remote,mappings:[{node_id,shot_id,kind}],context}`. Context must match the production; a graph's explicit context must also match. Remote selected history becomes an unreviewed take, preserves the human selection in the edit, and blocks final delivery until a local file is attached and reviewed. `attach` records provenance evidence and content hash. `adopt` applies an accepted take to one shot and its timeline references. Reconciliation must explicitly enumerate all terminal results and retain all known IDs; evidence closes an uncertain submission atomically. It does not authorize a new generation.

The approval identity includes revision, resolved intents, reference content, policy and reuse selection. `price_evidence.surface` must be `cli`; an API-only price is insufficient. The supplied evidence remains an operator-attested upper bound, not a provider-enforced price guarantee. `costs` emits known actual cost or null and retains unresolved exposure. Numeric provider media IDs are validated at the CLI boundary; Canvas IDs remain arbitrary strings.
